# 書籍翻訳・統合 PDF 制作ガイド

## 適用範囲

この `AGENTS.md` は `book-translations/` ディレクトリとその配下にだけ適用する。ほかの用途のプロジェクトへ、このディレクトリ固有の翻訳・統合ルールを持ち込まない。上位の指示と衝突する場合は上位の指示を優先し、判断できない場合は作業を止めて確認する。

## 目的

利用権限を確認できる複数の英語書籍を日本語へ翻訳し、出典との対応を保ったまま教育的・論理的に再編成して、単一の PDF として読める成果物を作る。正確な翻訳、編集上の再構成、要約、訳注・補足を区別し、読者が各記述を原資料まで追跡できる状態を維持する。

## 想定成果物

- 統合された日本語 PDF と、その再現可能な編集ソース
- 書誌、版、権利状態、使用範囲を記録した原資料台帳
- 統合 PDF の章節と各書籍の章節・ページを結ぶマッピング表
- 用語集、表記・翻訳スタイルガイド、記号表
- 訳注、補足、重複・矛盾、未解決事項の各記録
- 原文照合、引用、参照、PDF 表示に関する検証記録

完成 PDF だけを残して編集根拠を失わないこと。反対に、原資料や中間生成物を公開用成果物へ無差別に同梱しないこと。

## 推奨ディレクトリ・ファイル構成

既存プロジェクトでは既存構成を優先する。新規案件では、次を参考に構成案を提示し、採用前に確認を得る。ここに示す名前や階層は固定ではない。

```text
<project>/
  sources/             # 権利確認済み原資料または参照先。公開物と分離
  source-register.*    # 書誌・版・Source ID・権利・入手元
  rights.*             # 利用、引用、公開、配布の可否と確認記録
  planning/            # 対象範囲、章節マッピング、編集方針
  manuscript/          # 翻訳・統合本文の編集ソース
  glossary.*           # 訳語、表記、初出箇所、判断根拠
  style-guide.*        # 文体、表記、訳注、引用の規約
  notes/               # 訳注、矛盾、未確定事項、照合記録
  assets/              # 図表等。原資料由来と新規作成を区別
  build/               # 一時生成物。原則として本文ソースと分離
  dist/                # 配布候補の PDF と必要最小限の付属物
  qa/                  # ビルドログ、チェックリスト、検証結果
```

原文、翻訳ソース、加工素材、ビルド中間物、配布物を不用意に同じ場所へ置かない。原資料がリポジトリ管理に不適切なら、保管場所を文書化し、秘密情報を含まない参照情報だけを管理する。

## ツールチェーンの決定

- LaTeX、Typst、Pandoc など特定の方式を、この指示だけを根拠に生成・固定しない。
- 既存プロジェクトでは、既存のビルド方式、設定、命名、依存管理を優先する。
- 新規案件では、日本語組版、数式、索引、相互参照、長文の分割、再現性を比較した方式案と利点・制約を示し、確認後に最小構成を作る。
- 合意前に大量のテンプレート、依存パッケージ、生成設定を追加しない。

## 標準ワークフロー

1. **事前確認**: 対象書籍、版、翻訳範囲、想定読者、単一 PDF の構成、公開範囲、納期、既存ツールチェーンを確認する。
2. **権利と出典の登録**: 書籍ごとに一意な Source ID を付け、著者、書名、版、出版社、年、ISBN 等、参照ページ方式、入手元、利用根拠、公開・配布条件を記録する。
3. **構成設計**: 統合後の各章節について、対応する Source ID、原章節、版、ページ範囲、扱い（翻訳・要約・再構成・引用・補足）を章節マッピングへ記録する。
4. **用語設計**: 重要語の候補訳、採用訳、例外、初出説明、原語併記方針を用語集へ記録し、本文より先に基準を作る。
5. **翻訳**: 意味、論理関係、条件、否定、数量、定義、数式を原文に照らして訳す。意味の不確かな箇所を推測で確定せず、未確定マーカーと根拠を残す。
6. **統合編集**: 配列変更、要約、接続文、重複整理を翻訳作業と分離して行い、その変更種別と出典対応を記録する。
7. **照合**: 原文との対応、固有名詞、引用、数値、式、図表、ページ、用語の一貫性を確認する。重要箇所は可能なら翻訳担当とは別の視点で再確認する。
8. **ビルドと検証**: クリーンな状態から PDF を生成し、ログと目視の両方で確認する。
9. **公開判定**: 配布範囲、原資料・引用・図版の権利、ライセンス表示、成果物への不要ファイル混入を再確認し、権利確認後にだけ公開・配布する。

## 翻訳・再構成・執筆規約

- **翻訳**は原文の意味と構造を保つ作業、**要約**は情報を選択・圧縮する作業、**再構成**は順序や統合単位を変える編集作業として区別する。
- 章節単位で、翻訳・要約・再構成・直接引用・訳注・編者補足のどれに当たるか識別できるようにする。
- 原文にない説明、例、接続、評価、推論は `[訳注]`、`[編者補足]` など合意した表示で明示し、原著者の主張に見せない。
- 欠落や判読不能箇所を文脈から推測して埋めない。`[未確認]` 等で位置と理由を記録する。
- 同じ内容の重複は、無言で混ぜず、採用元・省略元・統合理由を記録する。
- 原資料間の矛盾は安易に解消せず、版の差、定義の差、文脈を確認し、必要なら両論と編集判断を注記する。
- 意味を変える意訳、説明の追加、節の移動は追跡可能にする。表現上の自然化と内容上の変更を混同しない。
- 文体、句読点、全半角、固有名詞、原語併記、敬体・常体、数字・単位、脚注形式をスタイルガイドで統一する。
- AI が生成した補足、候補訳、要約は人間が原文・出典と照合し、未検証のまま確定本文へ入れない。

## 書籍別の出典対応と原文照合

- 各出典には一意な Source ID を与え、版違いを別レコードとして扱う。
- 引用・翻訳・図表参照には、可能な限り Source ID、章節、版、ページ番号または電子版の安定した位置情報を付ける。
- 統合 PDF の各章節から原資料へ逆引きでき、原資料の使用範囲から統合先へも引ける章節マッピングを維持する。
- ページ番号は版に依存するため、番号だけでなく版情報を必ず組み合わせる。ページのない電子資料では位置指定方式を台帳に定める。
- 原文照合では、定義、列挙、比較、条件文、例外、否定、数量、専門用語、引用、数値、数式を重点確認する。
- 訳語変更は用語集へ反映し、既存箇所を検索して意図しない揺れを解消する。文脈依存の訳し分けは例外として理由を残す。

## 出典・引用・著作権

- 利用権限を確認できる原資料だけを扱う。権利状態が不明なら取得・翻訳・登録・公開のどこまで可能かを確認し、不可逆な作業を進めない。
- 原文の大規模転載を避け、検証と論述に必要な引用だけを、引用部分が明確な形で使用する。
- 引用は改変せず、脱落・強調・訳を加えた場合はその旨を明記する。二次資料からの孫引きを避け、原典を確認できない場合は明示する。
- 書誌情報、版、ページ、URL、参照日、ライセンス、許諾条件を再確認できる形で残す。
- 図版、表、装丁画像、スクリーンショットにも本文とは別の権利があり得るため、個別に確認する。
- 公開・配布は、翻訳権、翻案・編集、引用、図版、利用素材、配布先の条件を確認した後に限る。
- 秘密情報、購入資格情報、DRM 回避物、権利不明の原資料・素材をコミットしない。

## 数式・記号

- 原文の記号、添字、上付き、演算子、式番号、定義域、量化範囲を照合し、組版上の見た目だけで同一視しない。
- 書籍ごとに記号が衝突する場合は、原記号、統一記号、変換範囲、理由を記号表または編集記録へ残す。
- 記号を統一した場合、原文引用内は勝手に改変せず、本文側で対応を説明する。
- 数式内の文章、日本語フォント、行分割、番号、本文からの参照を PDF 上で確認する。

## 図表

- 図表ごとに出典、版、元番号、ページ、権利状態、扱い（引用・翻訳・改変・新規作成）を記録する。
- 原図を改変・再描画した場合は、その範囲と「原図を基に作成」等の表示を明確にする。
- 図表番号、キャプション、凡例、単位、本文からの参照を一致させる。色だけに意味を依存させず、縮小時の可読性も確認する。
- 一時画像、低解像度の確認用素材、権利不明素材を配布物へ混入させない。

## PDF ビルド

- ビルド手順、必要な依存、入口ファイル、出力先を文書化し、可能ならクリーン環境相当で再現できるようにする。
- 生成物と中間ファイルを編集ソースおよび原資料から分離する。
- ビルド成功だけで完了にしない。エラーに加えて警告、未解決参照、重複ラベル、欠落引用、目次・索引・しおり、式番号、図表位置を確認する。
- 日本語・欧文・数式フォントの埋め込み、代替フォント、文字化け、禁則、行末、脚注、余白、見開き、空白ページ、ページ番号、はみ出しを確認する。
- 最終候補は先頭・末尾だけでなく全ページを目視またはレンダリング検査し、章境界、ページ崩れ、画像解像度、リンクを確認する。

## 品質検証

- 原資料台帳の全使用資料に、版・権利・参照方式がある。
- 章節マッピングに空欄や孤立した統合節がなく、各内容の扱い種別が明確である。
- 用語集と本文を検索照合し、訳語・人名・書名・単位・表記の揺れを確認する。
- 定義、結論、数値、数式、直接引用、図表を重点的に原文照合する。
- 補足、未確定事項、AI 生成案が原著者の記述と視覚的・構造的に区別されている。
- 参照、脚注、目次、索引、ページ番号、PDF メタデータを確認し、検証記録に実施日・対象・結果・残件を残す。
- 差分とリポジトリ状態を確認し、原資料・中間物・秘密情報・無関係な変更が含まれていないことを確認する。

## 禁止事項

- 権利未確認の書籍を翻訳対象や公開物へ加えること。
- 翻訳を要約として削ったり、要約・再構成を逐語的な翻訳であるかのように提示したりすること。
- 原文にない内容、推測、AI 生成補足を無表示で原著者の主張へ混ぜること。
- 出典対応、版、ページ、訳注、矛盾を記録せずに統合すること。
- 原文の大規模転載、引用表示の欠落、権利不明素材のコミット・公開・配布。
- 合意なくツールチェーンを置換・固定し、既存のビルド方式やユーザー変更を壊すこと。
- ビルド成功だけを根拠に PDF を完成扱いすること。

## 完了条件

- 合意した全範囲が単一 PDF に収録され、構成、本文、目次、相互参照が整合している。
- 全章節について書籍別の Source ID、版、章節、ページ等への追跡ができ、翻訳・要約・再構成・補足の区別が明瞭である。
- 原文照合、用語統一、重複・矛盾処理、引用・権利確認が完了し、未確定事項は残件として明示されている。
- 合意した手順で PDF を再生成でき、警告、参照、数式、フォント、全ページのレイアウト検証を通過している。
- 配布対象に原資料、中間物、秘密情報、権利不明素材が混在せず、公開・配布条件が確認済みである。
