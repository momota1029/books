# Self-contained 数学講義ノート PDF 制作ガイド

## 適用範囲

この `AGENTS.md` は `self-contained-math-notes/` ディレクトリとその配下にだけ適用する。書籍翻訳や単一論文の読解ノートへ、このディレクトリ固有の全体系・証明依存ルールをそのまま適用しない。上位の指示と衝突する場合は上位の指示を優先し、判断できない場合は確認する。

## 目的

論理・集合・数学基礎から始め、合意した修士課程程度の到達範囲までを、完全に self-contained な講義ノート形式の PDF として構築する。初学者が各局所を追える説明と、高度な章まで破綻しない定義・記号・定理依存の全体整合性を両立させる。

## Self-contained の運用定義

このプロジェクトでの **self-contained** とは、次を満たす状態をいう。

- 各定義、命題、補題、定理、系、証明、例、演習が必要とする依存先を明示できる。
- 用いる語と記号が使用前または明示的な前提節で定義されている。
- 非自明な結果には原則としてノート内の証明があり、その証明が既に導入済みの公理・定義・結果だけに依存する。
- 公理、論理規則、規約、定義、証明済み結果、明示的なスコープ外依存を区別する。
- 未証明の非自明な結果を、暗黙の「よく知られている事実」として使わない。

self-contained は「参考文献が不要」という意味ではない。出典は歴史、標準的定式化、証明比較、追加学習、明示的なスコープ外依存のために正確に示す。

## 想定成果物

- 論理・基礎から合意した修士水準までを教育的順序で扱う講義ノート PDF
- 再現可能な編集ソースとビルド手順
- 全体カリキュラム、対象読者、到達目標、採用する基礎づけとスコープの文書
- 定義・定理・補題等の依存グラフまたは依存台帳
- 公理・論理規則・規約・既知事項・スコープ外事項の台帳
- 記号表、用語集、索引、参考文献、完全な相互参照
- 難度・依存節・ヒント/解答方針を持つ演習群
- 証明、依存関係、数式、参照、PDF 表示の検証記録

## 推奨ディレクトリ・ファイル構成

既存プロジェクトでは既存構成を優先する。新規案件では次を参考に構成案を提示し、採用前に確認を得る。名前と階層は固定ではない。

```text
<project>/
  scope.*              # 読者、到達水準、分野、基礎づけ、対象外
  curriculum.*         # 章構成、学習順序、到達目標
  foundations.*        # 公理、論理規則、規約、既知事項の台帳
  dependencies.*       # 定義・定理・補題等の依存台帳/グラフ
  manuscript/          # 章ごとの編集ソース
  glossary.*           # 用語と同義語
  notation.*           # 記号、意味、型、導入箇所、使用範囲
  exercises/           # 問題、難度、依存節、ヒント、解答
  references.*         # 書誌、使用箇所、スコープ外依存
  assets/              # 図表と作成根拠
  build/               # 一時生成物
  dist/                # 配布候補 PDF
  qa/                  # 依存・証明・ビルド・全ページ検証
```

参考資料、本文ソース、図表素材、検算用作業ファイル、ビルド中間物、最終 PDF を不用意に混在させない。巨大データ、権利制限資料、秘密情報はコミットしない。

## ツールチェーンの決定

- LaTeX、Typst、Pandoc その他の方式を、この指示だけで生成・固定しない。
- 既存案件では、既存の組版、分割、定理環境、索引、参考文献、ビルド方法を優先する。
- 新規案件では、長期保守、定理・式の相互参照、索引、依存台帳との連携、日本語・数式組版、差分可読性、再現性を比較した候補を提示し、確認後に最小構成を作る。
- 合意前にテンプレート、パッケージ、独自マクロを大量導入しない。独自マクロには意味と使用範囲を記録する。

## 全体設計と標準ワークフロー

1. **スコープ合意**: 想定読者、開始点、修士水準で扱う分野と深さ、採用する論理・集合論的基礎、古典/構成的立場、選択公理等の扱い、対象外を明文化する。
2. **カリキュラム設計**: 論理・集合/基礎から各分野への前提関係を整理し、章の学習順と到達目標を作る。分野を並べるだけでなく橋渡しとなる結果を特定する。
3. **基礎台帳作成**: 公理、推論規則、メタレベルの規約、定義、既知事項、スコープ外依存を分類する。「明らか」「標準的」を未分類の前提として使わない。
4. **依存設計**: 各定義・命題・補題・定理に安定した ID を付け、直接依存を台帳またはグラフへ登録し、使用前定義と循環参照を確認する。
5. **章執筆**: 原則として「動機・学習目標 → 定義 → 例/非例 → 命題・定理 → 証明 → 応用 → 節末要約 → 演習」の流れで書く。
6. **局所検証**: 新規の語・記号、証明の各推論、参照先、例、演習の解答可能性を章単位で確認する。
7. **全体検証**: 依存グラフ、記号表、索引、相互参照を更新し、循環、重複定義、意味変化、前方依存、章間のギャップを検査する。
8. **教育的レビュー**: 初学者が局所的に追えるか、同時に後続の修士水準で必要な厳密さ・一般性を損なっていないかを確認する。
9. **ビルドと PDF 検証**: クリーンな状態から生成し、警告と全ページの組版を検証する。

## カリキュラムと教育的な流れ

- 原則として、論理、証明技法、集合・写像・関係等の基礎から開始し、合意した代数、解析、位相、幾何、確率・測度、その他の修士水準分野へ依存順に進む。
- 分野の具体的な採否と順序は自動的に決めず、到達目標と依存関係に基づいて合意する。
- 各章の冒頭に前提節、学習目標、後続章での役割を示し、末尾に要約、依存の追加分、演習を置く。
- 定義の直後に典型例と非例を置き、境界を理解できるようにする。抽象化の前に必要な動機を示すが、直観を定義や証明の代わりにしない。
- 初学者向け説明では推論の段差を小さくし、高度な章では一般性を保つ。簡略化した説明が後で矛盾する場合は、適用範囲をその場で明記する。
- 既習扱いにしたい内容が生じたら、暗黙に飛ばさず、スコープを再確認して基礎台帳へ分類する。

## 定義・定理・証明の規約

- 定義、命題、補題、定理、系、例、反例、注意、演習を明確に区別し、安定したラベルを付ける。
- 定義は対象の型、量化範囲、必要条件、同値な定式化の扱いを明確にし、定義前にその語を本質的な意味で使わない。
- 定理には仮定と結論を明示する。証明では各非自明な推論に、定義、先行結果、公理、または直接の導出を対応させる。
- 「証明を省略」「同様」「明らか」「標準的」は、非自明な内容の代替として原則禁止する。「同様」を使う場合も変更点と同じ推論が成立する理由を示す。
- 計算証明では変形根拠、収束、定義域、零除算の回避、極限と演算の交換条件等を明示する。
- 存在を用いる前に存在、代表元に依存しないことが必要なら well-definedness、一意性が必要なら一意性を証明する。
- 反例と端点ケースを用いて仮定の必要性を検討し、定理の適用範囲を過大にしない。
- AI が生成した証明、例、反例は候補として扱い、全推論と依存を独立に検証するまで確定しない。

## 証明省略とスコープ外依存

- 非自明な結果の証明省略は原則禁止する。
- 例外は、合意したスコープ外であり、展開すると主目的を逸脱する場合に限る。単に証明が長い、難しい、または未完成という理由では省略しない。
- 例外を設ける場合は、結果を「スコープ外依存」と表示し、正確な定式化、必要な仮定、信頼できる出典と位置、使用箇所、採用理由を基礎台帳・依存台帳へ記録する。
- スコープ外依存を追加すると self-contained の境界が変わるため、利用前にスコープ文書を更新し、読者への表示を確認する。
- 未証明かつスコープ外として承認されていない結果は、後続の証明に使用しない。

## 依存グラフ・基礎台帳・循環参照

- 各項目に一意な ID、種類、導入箇所、直接依存、使用箇所、証明状態を記録する。
- 依存辺は「定義に必要」「証明に使用」「記法だけを使用」「動機上の参照」等、必要に応じて意味を区別する。
- 新規項目の追加時に、未定義語、存在しない ID、使用前依存、循環を検査する。
- 循環する説明と循環する論証を区別する。教育上の先取りは明示的な予告に留め、未証明結果を現在の証明へ逆流させない。
- 同値定理群を循環的に証明しない。基点となる結果と各含意の方向を明示する。
- 定義変更時は依存先と全使用箇所を検索し、定理、例、演習、記号表、索引の整合を再検証する。
- 依存台帳と本文が食い違う場合、どちらかを推測で正とせず、証明内容に基づいて修正する。

## 執筆規約

- 用語、文体、句読点、全半角、定理名、人名表記、数式前後の文章をプロジェクト内で統一する。
- 一つの段落に動機、定義、証明、補足を無差別に混ぜず、読者が論理的地位を判別できるようにする。
- 根拠のある数学的事実、教育上の直観、歴史的説明、未確定事項、AI 生成案を区別する。
- 欠落した証明や定義を推測で埋めない。`TODO`、未証明、要確認等を検索可能な形式で残し、完成判定から除外する。
- 参考文献の表現を要約・翻案する場合も出典を示し、独自説明と引用を区別する。
- 前の章だけを読めば次へ進めるよう、必要な結果には相互参照と短い役割説明を付ける。

## 数式・記号

- すべての記号を初出で定義し、意味、対象の型、定義域、添字範囲、導入箇所、使用範囲を記号表へ記録する。
- 同じ記号を近接する文脈で別の意味に再利用しない。分野慣習が衝突する場合は、局所記号であることを明示するか変更する。
- 論理記号、集合演算、写像、合成、同値関係、代数構造、位相・測度等の記法規約を基礎段階で定める。
- 等号、同型、同値、定義による等号、近似を区別する。対象を「同一視」する場合は正当化と有効範囲を示す。
- 式番号と本文参照を一致させ、演算子、太字、黒板太字、添字、括弧サイズ、改行を PDF 上で確認する。

## 演習・ヒント・解答

- 各演習に一意な ID、難度、依存する節または結果、狙いを付ける。
- 難度基準をプロジェクト内で定義し、少なくとも定義確認、基本適用、複合推論、発展を区別できるようにする。
- 各節に、理解確認と証明技法の定着に必要な演習を配置する。反例構成、仮定の必要性、例の計算も含める。
- ヒントを付けるか、完全解答を付けるか、別冊にするかをスコープで決め、全体で一貫させる。
- 解答または解答方針はノート内の導入済み事項だけで成立させる。外部結果が必要なら問題に明示し、依存台帳にも反映する。
- 問題文の不足、解なし、複数解釈、難度の不整合を実際に解いて検証する。

## 出典・引用・著作権

- 定義・定理の標準名称、歴史、証明の着想、例、演習、図表を資料から得た場合は、書誌と使用箇所を記録する。
- 直接引用は必要最小限にし、引用範囲と出典を明確にする。教科書や解答集の大規模転載・近接した書き換えを避ける。
- 定理自体と、その特定の表現・証明・図版の著作物としての扱いを混同せず、公開・配布前に権利を確認する。
- 孫引きを避け、原典未確認ならその旨を示す。歴史的主張は数学的証明とは別に出典を要求する。
- 外部の演習・解答、図版、データ、コードには個別の利用条件があり得るため確認する。
- 秘密情報、個人情報、権利不明のスキャン・画像・解答、契約で制限された素材をコミットしない。

## 図表

- 図表ごとに目的、作成者、出典、扱い（引用・改変・新規作成）、権利状態、依存する定義を記録する。
- 図は証明の代わりにせず、直観図と厳密な論証の役割を区別する。
- 軸、尺度、向き、境界、凡例、単位、色の意味を明示し、一般性のない一例を一般の場合に見せない。
- 図表番号、キャプション、本文参照を一致させ、白黒印刷、縮小表示、アクセシビリティ、画像解像度を確認する。

## 索引・相互参照

- 定義、主要定理、記号、人物・標準用語を検索できる索引または同等の導線を用意する。
- 定理・式・図表・章節・演習への参照は安定したラベルで管理し、手入力番号への依存を避ける。
- 用語集・記号表には導入箇所と主要使用箇所を付け、同義語・旧称・表記揺れを整理する。
- 参照先が読者の依存順より後にある場合は、予告なのか論証依存なのかを明確にし、論証の前方依存を解消する。

## PDF ビルド

- ビルド手順、依存、入口ファイル、出力先を文書化し、編集ソース、作業ファイル、中間生成物、配布物を分離する。
- ビルド成功だけで完了にしない。エラーと警告、未解決参照、重複ラベル、索引、参考文献、目次、しおり、定理・式番号を確認する。
- 日本語・欧文・数式フォントの埋め込み、グリフ欠落、文字化け、禁則、行間、脚注、余白、ページ番号、数式・表のはみ出しを確認する。
- 全ページを目視または画像化して検査し、章境界、定理環境、証明終端、長い式、可換図式、図表、索引、空白ページ、リンクを確認する。

## 品質検証

- カリキュラムとスコープが合意済みで、各章の前提・目標・後続での役割が明示されている。
- 自動検査または台帳レビューにより、未定義語、未定義記号、壊れた ID、使用前依存、循環参照、未証明結果の無断使用がない。
- 非自明な全結果に検証済みの証明があるか、承認済みスコープ外依存として出典・仮定・使用箇所が登録されている。
- 定理の仮定、証明の推論、例・反例、境界ケース、演習と解答方針を章単位・全体の両方で確認している。
- 記号表、用語集、索引、目次、参考文献、相互参照が本文と同期している。
- PDF の警告、参照、目次、数式、フォント、全ページの崩れを確認し、実施日・対象・結果・残件を記録している。
- Git 差分を確認し、中間物、秘密情報、権利不明素材、無関係な変更を含めていない。

## 禁止事項

- 未定義の語・記号、未証明の非自明な結果、暗黙の公理を、説明なしに使用すること。
- 「明らか」「同様」「標準的」「証明を省略」を、必要な証明の代わりにすること。
- 循環参照、使用前依存、定義の循環、同値命題同士の循環証明を放置すること。
- 根拠のない補足、推測、AI 生成証明を検証済み数学として本文へ混ぜること。
- 初学者向けの直観を厳密な主張と混同すること、または後続章で破綻する不正確な簡略化を無限定に述べること。
- 権利不明素材、秘密情報、大規模転載をコミット・公開すること。
- 合意なくツールチェーンや基礎づけを固定・変更すること、またはビルド成功だけで完成扱いすること。

## 完了条件

- 合意した論理・集合/基礎から修士課程程度の到達範囲まで、依存順に読める講義ノート PDF が完成している。
- 未定義語・未定義記号がなく、非自明な結果は原則として証明済みで、例外は承認済みスコープ外依存として出典・仮定・使用箇所が明示されている。
- 依存台帳またはグラフに欠落・循環・前方論証依存がなく、公理・規約・既知事項・スコープ外事項が分類されている。
- 各章が定義、例・非例、命題/定理、証明、応用、要約、演習の教育的流れを持ち、演習に難度・依存節・ヒント/解答方針がある。
- 記号表、用語集、索引、参考文献、相互参照が本文と一致し、初学者への局所説明と修士水準までの全体整合性がレビュー済みである。
- 合意した手順で PDF を再生成でき、警告、参照、目次、数式、フォント、全ページのレイアウト検証を通過している。
- 配布物に秘密情報や権利不明素材がなく、公開・配布条件が確認されている。
